# MonitorFlow 1.0

Windows 10/11 x64용 모니터 배치 및 마우스 경계 이동 보정 프로그램입니다.
`MonitorFlow.exe`를 실행하세요. .NET 런타임이 포함되어 있어 별도 설치가 필요하지 않습니다.

## 시작하기

1. **모니터 식별**을 눌러 각 화면의 번호를 확인합니다.
2. 화면을 드래그해 실제 책상 위 위치에 맞춥니다. 모니터 가장자리가 서로 닿아야 합니다.
3. 실제 화면 크기가 같으면 **같은 크기로 맞춤**을 누릅니다. 선택한 화면의 크기가 기준이 됩니다.
4. 크기가 다르면 화면을 선택하고 오른쪽에서 가로·세로 상대값을 입력한 뒤 **크기 반영**을 누릅니다. 예를 들어 같은 비율의 모니터가 한쪽은 20% 크다면 가로와 세로를 모두 1.2배로 입력합니다.
5. **배치 적용하기**를 누릅니다. Windows 디스플레이 설정에도 위치가 반영됩니다. 위치가 변경되면 15초 안에 **이 배치 유지**를 선택합니다. 확인하지 않으면 원래 위치로 돌아갑니다.
6. **마우스 보정 ON**을 켭니다. 적용한 화면 크기와 배치를 기준으로 모니터 사이 이동 위치를 보정합니다.

## ON과 OFF

- ON: 마지막으로 적용한 크기·배치를 기준으로 마우스 경계 이동을 보정합니다.
- OFF: Windows 기본 마우스 이동을 사용합니다. 이미 적용한 Windows 모니터 위치는 유지됩니다.
- 앱에서 편집 중인 설정은 **배치 적용하기**를 눌러야 보정에 반영됩니다.
- **이전 배치 복원**: 직전 Windows 위치와 연결 기준 크기를 복원하고 보정을 끕니다.

실제 해상도, Windows 배율, 주 모니터 설정은 변경하지 않습니다. Windows 설정에 표시되는 모니터 사각형 크기도 기존 해상도 기준으로 유지됩니다.

## 단축키와 트레이

| 기능 | 단축키 |
| --- | --- |
| 보정 즉시 중지 | **Ctrl + Alt + Shift + M** |
| 앱에서 보정 ON/OFF | Ctrl + M |
| 앱에서 배치 적용 | Ctrl + Enter |
| 화면 위치 미세 조정 | 화면 선택 후 방향키, Shift를 누르면 10단위 |

보정 ON 상태에서 창을 닫으면 트레이에서 계속 실행됩니다. 트레이 아이콘을 두 번 클릭하면 창이 열립니다. 트레이 메뉴의 **종료**는 보정도 종료합니다. 보정 OFF 상태에서 창을 닫으면 앱이 종료됩니다.
다시 실행하면 저장한 배치를 불러오고, 보정은 OFF로 시작합니다. Windows 위치를 시작 시 자동 변경하지 않습니다.

## 여러 모니터와 배치 제한

- 연결된 모니터 수를 자동으로 인식합니다. 2·3·4개를 포함해 여러 모니터를 처리하는 구조입니다.
- 가로·세로 배치와 부분적으로 맞닿는 경계를 지원합니다.
- 화면이 겹치거나 서로 떨어져 있으면 적용 전에 알려줍니다. 모서리 한 점만 닿는 배치는 연결로 보지 않습니다.
- 해상도가 다른 모니터의 일부 2×2·복잡한 배치는 Windows의 픽셀 좌표로 변환할 때 겹칠 수 있습니다. 이 경우 적용을 중단하고 안내합니다. 가로·세로 정렬이나 배치 오프셋을 조절해 주세요.
- 모니터 연결·해상도·Windows 위치가 외부에서 바뀌면 보정을 중지하고 다시 읽습니다.
- 일반 Windows 데스크톱의 상대 마우스 입력을 대상으로 합니다. 독점 전체 화면 게임, 마우스를 가두는 앱, 절대 좌표 펜·태블릿, 원격 데스크톱은 별도 호환성 검증 대상입니다.

## 저장 위치

설정은 `%LOCALAPPDATA%\MonitorFlow\layout.json`에 저장됩니다. 배치 변경 확인 중에는 `pending.json`으로 복구 정보를 남깁니다. 비정상 종료 뒤 앱이 복구 정보를 감지하면 **이전 배치 복원**으로 되돌릴 수 있습니다.
클라우드 전송, 계정 로그인, 자동 시작 등록은 없습니다.

## 검증 범위

- 기하 계산 테스트 19개 통과: 2·3·4개 화면, 상하좌우 이동, 음수 좌표, 경계 막힘, 크기 변경, 해상도 유지, 잘못된 배치 등.
- 실제 QHD + FHD 환경에서 화면 조회, Windows 위치 변경, 15초 자동 복원 확인.
- 실제 앱에서 마우스 ON 및 즉시 중지 단축키 동작 확인.
- 네이티브 마우스·키보드 훅과 Raw Input 등록·해제 반복 확인.
- 실제 하드웨어 마우스로 경계를 넘을 때의 이동감은 사용 환경에서 추가 확인이 필요합니다. 자동화 입력은 보정 대상에서 제외됩니다.
